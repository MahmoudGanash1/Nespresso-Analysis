# ☕ Nespresso Sales Performance Dashboard (Excel)

An interactive Excel-based sales analytics dashboard designed to analyze **sales performance, customer behavior, product trends, and revenue anomalies** for Nespresso.

The project provides a multi-dimensional view of business performance using Excel tools such as Pivot Tables, Charts, and Slicers.

---

## 🎯 BUSINESS OBJECTIVE

The objective of this dashboard is to:
- Track overall sales and revenue performance  
- Analyze product and category contribution  
- Understand customer purchasing behavior  
- Evaluate channel and regional performance  
- Detect anomalies in sales trends  
- Support data-driven decision-making  

---

## 💡 SOLUTION

Developed an interactive Excel dashboard that:
- Consolidates raw sales data into structured analysis  
- Uses Pivot Tables for dynamic aggregation  
- Applies slicers for interactive filtering  
- Provides multiple analytical views across business dimensions  

---

## 🛠 TOOLS & TECHNOLOGIES

- Microsoft Excel  
- Pivot Tables  
- Charts & Data Visualization  
- Slicers & Filters  
- Data Cleaning & Structuring  

---
